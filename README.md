## 🚀 Features

SmartReply AI integrates seamlessly into web applications to read your context and generate the perfect response, post, or prompt.

- **Context-Aware Replies**: Instantly generates replies by reading the thread or post you are replying to.
- **Smart Compose**: Generates posts from scratch based on a topic you provide.
- **Prompt Enhancer**: Automatically detects AI chat interfaces (ChatGPT, Claude, Gemini, Perplexity) and rewrites your initial prompt into a highly optimized, structured prompt for better AI results.
- **Tone & Language Control**: Adjust the tone (Friendly, Professional, Casual) and language (English, Hindi, Hinglish) of the generated text.
- **"Humanize" Toggle**: Injects slight imperfections and conversational nuances to make AI-generated text sound authentically human, avoiding common "AI vibes".
- **Draggable UI**: Move the SmartReply trigger buttons and action panel anywhere on the screen for an unobstructed workflow.
- **Keyboard Shortcuts**: Hit `Ctrl + Enter` (or `Cmd + Enter`) to quickly generate a reply.
- **Privacy-First Native Feeling UI**: Looks and feels like a native part of the website with premium glassmorphism design.
- **Frictionless Insert**: One-click insert directly into the text box you're focused on, bypassing hostile focus-traps from platforms like LinkedIn.

## 🔗 Supported Platforms

SmartReply AI has tailored logic for extracting context and inserting text on:
- **LinkedIn** (Posts, Comments, and Direct Messages)
- **Twitter / X**
- **Gmail**
- **Reddit**
- **WhatsApp Web**
- **YouTube**
- **AI Chatbots** (Prompt Enhancer mode on ChatGPT, Claude, Gemini, Perplexity, Copilot)
- *Generic fallback for standard textareas on any other web page.*

## 🛠 Installation (Developer Mode)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/smartreply-extension.git
   cd smartreply-extension
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build the extension:**
   ```bash
   npm run build
   ```

4. **Load into Chrome:**
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable **Developer mode** in the top right corner.
   - Click **Load unpacked** and select the `dist` directory generated by the build step.

## 💻 Tech Stack

- **React Element Injection**: Renders a floating React panel natively inside the webpageDOM.
- **Vite & CRXJS**: Lightning-fast builds specifically tailored for Chrome Extensions via `@crxjs/vite-plugin`.
- **Vanilla CSS**: Scoped, isolated CSS to prevent bleed-in or bleed-out of website styles using `all: unset` resets.
- **Sarvam AI API**: Powered by the Sarvam-M model for high-quality, multilingual generation.

## 🎯 How it Works

1. **The Trigger**: The extension attaches a `focusin` event listener to the document. When you click inside any valid text input, it injects the `SR` button nearby (or an `Enhance` pill for AI sites).
2. **Context Mining**: By walking the DOM tree of supported platforms, the extension identifies the exact text you are replying to—even deeply nested comments on LinkedIn or threaded replies on Reddit.
3. **The Panel**: Opening the panel provides controls to tweak the system prompt.
4. **Injection**: Text insertion utilizes `document.execCommand("insertText")` coupled with native DOM setter invocation (`Object.getOwnPropertyDescriptor().set`) to ensure React/Angular controlled inputs (like LinkedIn's or WhatsApp's) register the change.
